다운로드 순서

  1. 다운로드 키를 입력합니다.담당자로부터 전달받은 키를 그대로 입력하세요.
  2. ZIP 파일을 저장합니다.다운로드가 시작되면 안전한 작업 폴더에 저장하세요.
  3. 매뉴얼을 확인합니다.지원 OS, 파일 검증과 실행 순서를 확인한 뒤 시작하세요.

다운로드 키는 파일을 받는 데만 사용하며 Worker 실행 인증에는 사용하지 않습니다.

BEFORE YOU START

다운로드 전에 확인하세요

01 · KEY전달받은 키 준비

키를 URL이나 메신저 공개 채널에 붙이지 마세요.

02 · VERIFY파일 무결성 확인

게시 후 표시되는 SHA-256과 서명 정보를 기준으로 확인합니다.

03 · OFFLINE설치 안내 확인

지원 OS와 선행 조건은 함께 제공되는 오프라인 매뉴얼을 따릅니다.
